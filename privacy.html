Privacy Policy

Effective: November 16, 2026.

LevelProof Gaming is a creator-operated tool for editing and uploading videos to the channel owner's YouTube account.

Data accessed

With the account owner's OAuth consent, this app uses the YouTube Data API scopes youtube.upload and youtube.readonly. It reads the authorized channel identity to check that uploads target the intended LevelProof Gaming channel, and it uploads videos and accompanying metadata when the channel owner authorizes publication.

Data use and storage

OAuth client credentials and refresh tokens are stored in private GitHub Actions repository secrets and are used only to obtain temporary access tokens for authorized API operations. Tokens are not committed to source code. The workflow may keep operational status, YouTube video IDs, and limited export diagnostics in private repository status files or short-lived GitHub Actions artifacts. These records are used to monitor authorized operations and troubleshoot failures.

Sharing and retention

Data is sent to Google's OAuth and YouTube APIs to provide the service, and processed by GitHub Actions to execute the workflow. We do not sell Google user data, use it for advertising, or share it with independent advertisers. OAuth credentials remain until the owner removes them or revokes authorization. Local processing files are temporary; operational status records may remain until the owner deletes them.

Control and revocation

The channel owner may revoke the app's access in Google Account security settings and remove the repository's GitHub Actions secrets. The owner can also delete stored status records in the repository and uploaded videos through YouTube Studio.

Contact

For privacy-related inquiries, contact the creator via the public website support issues, or the developer contact on the Google OAuth consent screen.
